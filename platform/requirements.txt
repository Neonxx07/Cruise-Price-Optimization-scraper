# Robust price/date text parsing (msc_commands.py) -- ADDED 2026-08-24,
# researched and tested against this project's own real captured strings
# before adopting. Replaces hand-rolled regexes that require an EXACT
# format (e.g. "\d+\.\d{2}", exactly 2-digit month/day) and silently
# return no match at all on a real, valid variant -- the same bug CLASS
# already confirmed once on GoCCL (a whole-dollar "$1,418" with no cents
# broke a regex requiring exactly 2 decimal digits). price-parser handles
# whole-dollar amounts, stray spaces, and currency prefixes; dateparser
# handles non-zero-padded dates ("8/9/2026") the project's own rigid
# \d{2}/\d{2}/\d{4} pattern would silently fail to match. Neither library
# preserves a negative/parenthetical sign on its own -- that detection
# stays as its own separate, already-existing check in msc_commands.py.
price-parser>=0.3.4
dateparser>=1.2.0
